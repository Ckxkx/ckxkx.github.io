## 运行博客

本网站使用 Hexo 和 Fluid。安装 Node.js 22 后，执行 `npm ci` 安装依赖，执行 `npm run server` 本地预览。文章保存在 `source/_posts/` 下的分类文件夹，推送到 `main` 后通过 GitHub Actions 自动发布。
