## ⁠2 ⁠后端环境搭建

### ⁠2.1 ⁠sky-take-out目录结构
1.sky-take-out maven父工程，统一管理依赖版本，聚合其他子模块
2.sky-common 子模块，存放公共类：工具类，常量类，异常类
3.sky-pojo 子模块存放实体类：VO，DTO
4.sky-server 子模块，后端服务，存放配置文件，controller、server、Mapper等

### ⁠2.2 ⁠四类简写
- Entity 实体
- DTO 数据传输对象
- VO 试图对象，为前端展示数据的对象
- POJO 普通Java对象，只有属性和对应的getter和setter

### ⁠2.4 ⁠nginx反向代理
前端：http://localhost **/api/** employee/login
后端：http://localhost:8080/admin/employee/login

#### ⁠2.4.1 ⁠反向代理
nginx.conf:

location /api/ {
	proxy_pass   http://127.0.0.1:8080/admin/;
}

匹配api,将api前半部分换成代理后的地址
**http://localhost:8080/admin/** employee/login

#### ⁠2.4.2 ⁠负载均衡

upstream webservers{
server 127.0.0.1:8080 weight=90 ;
server 127.0.0.1:8088 weight=10 ;
}

#### ⁠2.4.3 ⁠nginx的作用
1. 提高访问速度（nginx可设置缓存）
2. 负载均衡（将前端发来的请求路由给多台服务器）
3. 保证后端安全（不暴露后端地址）

#### ⁠2.6.3 ⁠Swagger常用注解

作用：让Swagger测试界面更直观清晰

- @Api 用在类，例如Controller，表示对类的说明  @Api(tags = "员工常见接口")
- @ApiModel  用在类上，例如entity，DTO，VO
- @ApiModelProperty 用在属性上，描述属性信息
- @ApiOperation   用在方法上，例如Controller说明方法的用途，作用
